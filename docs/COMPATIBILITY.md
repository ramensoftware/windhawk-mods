# 兼容性

| 范围 | 结果 |
| --- | --- |
| 本机 Windows 11 26H2 x64，构建 `26300.9974` | 运行中确认 ShellHost 模块，匹配三个系统 DLL 的公开 PDB，音频探针成功运行 |
| Windows SDK `10.0.26100.0` 与 MSVC x64 | 探针编译并链接，WinRT 诊断和 Windhawk API 声明通过编译到对象文件 |
| Windhawk 1.7.3 便携版 x64 | 使用自带 Clang 编译并链接诊断。实际加载到 ShellHost，捕获到任务栏声音输出页的一次混合器焦点事件及 4 个应用行 |
| Windows 11 24H2 x64 及其他更新 | 产品兼容目标，尚无 GUI、策略和镜像回归数据 |
| ARM64 | 当前诊断声明为 x86-64，ARM64 源码与运行行为待验证 |
| HDMI、板载数字输出 | 本机 WASAPI 渲染写入通过，硬件播放、输出时延和漂移待测 |
| 蓝牙及休眠唤醒 | 待人工或设备台架验证 |

Windows 软件更新可单独替换系统 DLL。每个包含新 DLL 的构建都需重新验证符号、XAML 结构和逐应用策略。诊断缺少确切符号时初始化失败。产品还需要在运行时身份不明确或接口探测失败时禁用对应操作。
