## 2.0.0 ([Oct 28, 2026](https://github.com/ramensoftware/windhawk-mods/blob/c7cf229cda461c3c3eb38fb92e0513f04d003a77/mods/psp-dark-mdi-frames.wh.cpp))

* Renamed to "PaintShop Pro Dark Mode"; it now darkens the whole interface, not only the image windows.
* New setting: interface darkness for the dark gray surfaces (tool bars, tool column, palettes, tool options bar, dialogs and the area around the color wheel).
* New setting: title bar color of the main window (black by default).
* New setting: accent color that replaces the orange of the "Edit" tab and of the line below the title bar.
* New setting: hide the eight start tiles in the empty workspace (off by default).
* Image window frames and the flash fix are unchanged.
