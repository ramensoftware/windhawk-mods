## 1.1.0 ([Nov 14, 2026](https://github.com/ramensoftware/windhawk-mods/blob/5d7506d753a4a65ec7ee938a0b9fcb6c165476e1/mods/unlock-folder-in-use.wh.cpp))

* Replaced the standard Windows task dialog with a custom prompt window that follows the Windows app theme (dark mode), uses the system accent color, scales with per-monitor DPI and supports keyboard navigation.
* Added the "Expand details by default" setting. The details list (matched items, processes and windows) now starts expanded, and can be set to start collapsed.
* Removed the "modernDialogs" setting and the message box fallback, as the new prompt no longer depends on the task dialog.
* Updated the readme with before/after screenshots.
