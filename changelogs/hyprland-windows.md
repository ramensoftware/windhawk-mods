## 1.2.1 ([Nov 2, 2026](https://github.com/ramensoftware/windhawk-mods/blob/16e402d6bbc717c0cceb7e9262a8b52694842a7e/mods/hyprland-windows.wh.cpp))

* Win + mouse wheel makes a window larger or smaller, around its center or the cursor, also while it is being moved; two fingers on a touchpad do it too.
* Win + mouse now works over WinUI and XAML content as well (Paint, Windows Terminal, the tabs of File Explorer).
* A new setting: Win + Alt + left mouse button resizes a window, for a touchpad.
* A new setting for a click with the modifier held and no movement: with Alt it goes to the app by default, with Win it grabs the window.
* Win+Tab with no other desktop that has windows goes to an empty one, made if need be (can be turned off).
* A hidden menu bar no longer flickers: it shows up only while the keyboard is in it (Alt or F10).
* The window shortcut closes any window Alt+F4 would, Task Manager included.
* Fixes: Alt as the modifier works with Aero Snap and no longer opens menus, Esc cancels an Alt drag, closing an elevated window with Win held no longer opens Start, a window slow to resize keeps up with the cursor, and Win+Tab is left to Task View while it is open.
