## 0.3.13 ([Nov 28, 2026](https://github.com/ramensoftware/windhawk-mods/blob/99a0b0a78541f096b8e192e843447571e8fe4cb7/mods/text-capitalization.wh.cpp))

- Shortcuts now accept a letter (A-Z), a digit, F1-F24, or a numeric VK code (decimal or hex).
- Improved Title Case (minor words) and Sentence Case.
- Picker is now more reliable (reused window, no stuck state).
- AltGr no longer triggers shortcuts; missed key-ups no longer leave modifiers stuck.
- Full clipboard snapshot and restore; the pasted text is kept out of clipboard history.
- Console/terminal windows are ignored.
- The four picker-key settings (PreviousModeHotkey, NextModeHotkey, ConfirmModeHotkey, CancelPickerHotkey) were removed; picker keys are now fixed to Up/Down/Enter/Esc.
