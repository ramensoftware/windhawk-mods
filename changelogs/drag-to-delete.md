## 1.1.0 ([Nov 13, 2026](https://github.com/ramensoftware/windhawk-mods/blob/65feabc14ab993c83f5a27bc88216e9d0b948bc6/mods/drag-to-delete.wh.cpp))

* Placement modes: Added Follow cursor, Nearby, and Top.
* Ctrl+Z undo: Added native Shell undo via IFileOperation.
* System icon option: Added sharp native Windows Recycle Bin icon.
* Optional shadow: Added toggleable ShowShadow setting.
* Distance auto-hide: Target fades out when dragging far away.
* Fullscreen Z-order fix: Stays visible over fullscreen background windows.
* Search drag support: Recycles Everything & Power Tools search items.
* Desktop Shell items: Added support for CFSTR_SHELLIDLIST desktop selections.
* Virtual item filtering: Safely ignores non-filesystem virtual items.
* Dynamic monitor DPI: Automatically updates scaling across different monitors.
