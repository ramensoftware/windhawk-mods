## 1.2 ([Nov 19, 2026](https://github.com/ramensoftware/windhawk-mods/blob/117a781f71dc5f3cf24815e2cda3a6773dba286c/mods/taskbar-auto-hide-speed.wh.cpp))

* Added animation options that make the auto-hide feel more smooth and natural.
* The animation now syncs to the display refresh rate, making the animation more smooth. It can be disabled in the settings if a custom refresh rate is desired.
* Improved the accuracy of the custom refresh rate timer.
* Fixed the "Customize the old taskbar on Windows 11" option on Windows 11 24H2 builds before 26100.1301, which still include the old taskbar.

The first two changes were contributed by [Eduard Olteanu](https://github.com/eduard-lt).
