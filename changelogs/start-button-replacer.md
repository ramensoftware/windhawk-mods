## 1.0.0 ([Nov 15, 2026](https://github.com/ramensoftware/windhawk-mods/blob/dabac878f1673e94f3af838f639d82dbb81b48ac/mods/start-button-replacer.wh.cpp))

* Added SVG support for all image sources (local files and HTTP/HTTPS URLs ending in `.svg`). Only static SVG content is rendered.
* Added optional **Dark mode images** that replace the main images while Windows is in dark mode. Blank fields use the main images, and images switch automatically when the Windows mode changes.
* Image load warnings now show which settings group the failed image belongs to.
* Added a Credits section to the readme. Thanks to [Asteski](https://github.com/Asteski) for SVG support and dark mode images.
