* Added `allMonitors` setting to replicate overlay indicators and borders across all connected displays.
* Added `redBorderMode` and `redBorderThickness` settings to render a red screen frame while muted.
* Added `muteAllMicrophones` setting to toggle mute across every active capture device.
* Added `modToggleHotkey` setting to enable or disable the mod dynamically.
* Added `showOnlyWhenMuted` setting to display the indicator exclusively when muted.
* Refactored render target caching into a multi-slot system and implemented auxiliary window management for multi-display rendering.
* Updated mod metadata, localized descriptions, and README documentation.
