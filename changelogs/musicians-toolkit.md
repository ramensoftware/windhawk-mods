## 1.1.0 ([Nov 16, 2026](https://github.com/ramensoftware/windhawk-mods/blob/8fa7b422e503fe02d38ccedc8ea46ba85d020f95/mods/musicians-toolkit.wh.cpp))

* Added a tray icon: a click opens or closes the panel, a right-click names every tool so one can be opened in a step. It can be switched off under Settings > Placement, and it follows the accent colour.
* The icon comes back by itself if Explorer restarts.
* **Shift+Tab** switches instrument in every tool that has more than one, stepping back each time.
* **Tab** steps the instruments forward in the Tuner as well, so the two keys work as a pair. On *Chords* it still plays the chord, and on *Strumming* it still walks the pattern list.
* **Space** and **Enter** play the chord on *Chords*.
